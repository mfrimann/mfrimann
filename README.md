# Unraid Custom WebUI CSS Builder

Et simpelt værktøj til at bygge og previewe et custom Unraid WebUI tema, så du kan kopiere den genererede CSS direkte ind i plugin'et **Custom WebUI CSS**.

## Features

- Live preview af et Unraid-lignende dashboard layout.
- Farvejustering af primær/accent/baggrund/surface/sidebar m.m.
- Fontvalg fra Google Fonts.
- Justering af basisskriftstørrelse, border radius og skygge.
- Auto-genereret CSS, klar til copy/paste i Unraid plugin.

## Kør lokalt

Åbn `index.html` direkte i browseren, eller start en lille webserver:

```bash
python3 -m http.server 4173
```

Besøg derefter `http://localhost:4173`.
