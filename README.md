# Podcast Tracking Tool

Et responsivt podcast tracking værktøj med:
- Podcast/episode CRUD
- Bulk actions i episode-tabellen
- Google Sheets import (tab- eller `|`-separeret) + import-guide modal
- Podcast billeder i oversigt og detaljevisning
- Valgbar afspilningshastighed: 1x til 2x (inkl. 1,1x ... 1,9x)
- Statistik og dark mode
- JSON backup import/export

## Kør lokalt

```bash
python3 -m http.server 4173
```

Åbn derefter `http://localhost:4173`.
